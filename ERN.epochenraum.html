ERN · Epochenraum

Epochenraum = Wiederkehr im Raum

ERN.epochenraum:
Epoche = kommen → sein → gehen → zurückkehren
Raum   = a → b → c

Jede Epoche trägt:
◉ Ursache
◎ Wirkung
▣ Ergebnis
Σ Wiederkehr

Epochenraum-Schichten:
Startboden  = a
Flussboden  = b
Tiefenboden = c

Epochenraum ist:
ein Kreis im Raum
ein Raum im Kreis
ein Wiederkommen im Verlauf
